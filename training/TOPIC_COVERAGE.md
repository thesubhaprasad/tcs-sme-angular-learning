## Framework differences taught explicitly

- JSX → Angular templates, interpolation and bindings; standalone imports replace JSX imports alone.
- Props → input signals; callback props → outputs; children → ng-content.
- Array map/keys → @for/track; @if handles conditions without React numeric-zero rendering semantics. JavaScript map/filter remain useful for data.
- useState → signal; useMemo-like derivation → computed. Angular signal writes are synchronous; a previously captured value stays unchanged. React Hook call-order rules do not apply.
- useEffect/fetch → ngOnInit, ProductService, HttpClient Observables, DestroyRef and takeUntilDestroyed. Promise/fetch, response.ok and AbortController remain reference background. Angular dev checks are not React Strict Mode effect cycles.
- Custom Hook → provider-scoped injectable store plus pure helpers; sharing depends on provider scope.
- Controlled inputs → explicit DOM bindings, ngModel or typed reactive FormControls; ngSubmit handles submit events through the forms directives.
- React production build → ng build; router, guards, interceptors, testing and deployment are additional Angular references.
